# Lo-fi DV 私人影像创作

作者：江珊珊。一个用于私人生活影像的风格与创意 Skill，从照片、视频或简短生活场景想法出发，设计静帧、独立短视频与生活片段系列。

## 核心方法

让可信的生活关系、旁观取景与受损成像共同成立：大形可读，小纹理混掉，人物不为了镜头展示自己。

- 成像：低解析、粗颗粒、柔糙渗色，人物与环境共同损失细节。
- 光色：有区域的冷暖、有颜色的暗部、少量局部鲜色与不完美曝光。
- 行为：有生活动机的微动作、明确身体支撑、自然克制的表演。
- 流程：先分析参考并明确继承范围，再选择方案、制作和针对偏差修订。

## 如何使用

向支持读取 Markdown 的 Agent 提供本仓库，先阅读 SKILL.md，再按任务阅读 references 中的文档。实际生成需要兼容的图像或视频工具，本仓库本身不提供媒体生成服务。

示例请求：

> 使用这个 Skill，围绕朋友夏天傍晚一起等公交，提出三个不同的生活画面方案。保留低解析、粗颗粒与自然现场光，先给方案，暂不生成。

> 分析我上传照片的成像、构图和人物关系。区分看得见的事实与推测，提炼可用于新场景的视觉要求。
