# Lo-fi DV生成表达与修订

## 从观看目标到表达顺序

先写画面要让人看懂的生活关系，再写实现它的姿态、场景与机位。建议依次组织：参考职责 → 场所与人物 → 开场关系与支撑 → 景别、遮挡和重心 → 一次动作及结束状态 → 光色区域 → 贯穿近远的受损成像 → 现场声音 → 本场面排除项。

不要只堆叠Lo-fi、复古、胶片、cinematic等标签。低解析须说明损失哪些信息、保留哪些大形：近脸手与背景同受影响，发丝织物小纹理糊合，但两个人头颈、腕掌归属、道具落点仍可读。渗色不是强RGB分裂，曝光不完美不是全图闪白。

## 生成要求模板

- 继承：主身份素材负责哪位人物的可见外观；场所或道具素材负责哪些形体；成像素材负责粗颗粒、低解析、冷暖分区或时间性。明确不继承的布景、人物或动作。
- 场面：地点、时段、人数、衣物、彼此位置和生活目的。关系为成年人情侣时明确普通完整着装。
- 构图：从哪里看，画面重心在哪里；哪些部分可遮、哪些接触必须看见；亮窗或鲜色的面积与主次。
- 开场：动作已经准备好，身体各自有支撑。
- 中段：一个核心动作，必要时一次轻回应；手与道具短路径，不编高负荷连锁步骤。
- 结束：靠稳、停手、继续看向画外或安静呼吸，不自动加剧情转折。
- 成像：近人与远景共同密粗颗粒色噪、低解析细节混合、柔糙渗边、有色暗部与局部暖肤冷亮、克制非均匀曝光漂移。
- 声音：与场所对应的轻现场声。排除自动对白、配乐、字幕及与本案无关的行为。

模板是目标与信息骨架，不是固定的模型调用格式。把确实需要的参考职责写进正向目标，避免只靠长篇排除词补救不清楚的场面。

## 三种可复用关系例子

- **照料与回应：** 浴室门边，一人已持毛巾在恋人湿发上，轻擦一次后停；对方搭其手腕。门边斜近景，脸被头发部分遮，手腕归属和触点清楚。声音是毛巾衣料，不完整洗头过程。
- **眼神错位：** 镜前两人准备合照，一人主握唯一相机，另一人从下方托稳；前者按键前侧眼看恋人，后者还看镜子。写清真实两人、同一设备与同一反射关系，不产生第三人或第二相机。可有一次轻快门声，不插入生成照片。
- **持续承接：** 坐着的情侣开场已侧靠胸肩，各自髋腿仍由座面支撑，一掌贴肩背。头只放松几度、掌指轻收后停。构图保留接触证据，不为私密把所有侧脸与头颈压成暗团。

例子中的衣色、人数和地点按任务替换，不构成每次必须使用的情节。

## 构图修订范例

问题：窗边两人被压在底部，亮窗占据上半幅，暗墙留白过大，头肩接触成暗团，身体横向铺开导致两端截背截腿。

修订目标：仍在窗边并坐，改为坐姿肩高斜侧中近景，主要收头肩、上半身和贴肩手，不带腿脚；人物移至画面中部，略露侧脸与另一人的下颌，使两人头颈独立。窗光缩到一侧边缘，窗帘只从边缘轻拂发侧。通过取景和现场光方向改善关系可读性，不加美肤棚拍光。保留低解析、粗颗粒、有色暗部与轻渗色。

这是已识别缺陷对应的目标，不是所有近景的固定构图，也不证明任何一次生成已完全实现目标。

## 手部与局部修订

用画面位置、袖口与参与动作定位问题手，不在解剖左右尚不清楚时强设左手或右手。要求腕掌方向连贯、拇指位置自然、掌指比例正常、两人接触边界独立；缩小翻掌幅度和交叉动作，不以加重模糊、遮挡或更粗颗粒解决。

如果旧片后段持续出现手变形，仅用稳定前段或可靠身份、布局素材辅助；不要把含缺陷的整片当作动作范本。构图失败亦如此：若目标是新机位，应优先用可靠人物与成像依据，不绑定失败构图让它重新主导。

## 成像偏差修订

- 太干净：加强近人与背景共同低解析、颗粒与细节糊合，不只增加细点噪声。
- 太白太灰：改有颜色的沉暗区域与局部暖冷光，保留中间调，不全图蒙白。
- 鲜色分离：让衣物、红座位与亮点同受成像损失，避免独立锐利色块贴在背景上。
- 背景像绿幕：要求真实深浅层次与不规则大形，保留局部阴影，不全图染绿或恢复高清叶纹。
- 味道变写真：移除精致补光、皮肤美化、强浅景深和展示式姿态，恢复现场光与旁观取景。

修订时同时更新文字中的参考职责与实际绑定，不能留下已移除素材的显式引用。保留当前场面有效部分，只纠正已识别的偏差。
